# forge-ui → shadcn/ui component parity

> The Lit web components (`@driveforgelabs/forge-ui`) and React wrappers (`@driveforgelabs/forge-ui-react`) have been removed from this repo and remain in git history. This table is the migration reference for apps that still import them.

Replacement library: `@driveforgelabs/ui` (the repo root), stock shadcn/ui (new-york, stone base, Radix) with the Clay theme. Composed items (StatusBadge, StatCard, ...) live in the same package and install via the `@clay` registry.

Conventions that apply to every row:

- forge components are Lit custom elements: state in, **`forge-*` CustomEvents** out (`e.detail.value`, `e.detail.checked`). shadcn components are React: controlled props and callbacks (`value` + `onValueChange` / `onChange`, `checked` + `onCheckedChange`, `open` + `onOpenChange`).
- forge inputs own their label, hint and error state (`label`, `hint`, `state="error"`). In shadcn you compose `Label`, the control, and helper text yourself (or use `Form`); error state is `aria-invalid`.
- forge uses `ForgeX` wrappers from `@driveforgelabs/forge-ui-react`; shadcn components are imported from your app's `@/components/ui/*`.

"Mecano" column: number of imports in Mecano today, from the migration brief (– = not in its list).

## No direct equivalent

- `forge-virtual-list`: use `@tanstack/react-virtual` (not installed here).
- "No equivalent, keep using forge-ui" no longer applies: the forge packages are gone, so apps must migrate every component they use. Gauges, heat cells, number ticker, timeline, file upload and similar now have composed replacements (see the table above).

## New since the first pass

Stock added through the CLI: `alert-dialog`, `aspect-ratio`, `button-group`, `carousel`, `context-menu`, `empty`, `field`, `hover-card`, `input-group`, `input-otp`, `item`, `kbd`, `menubar`, `navigation-menu`, `pagination`, `spinner` (the deprecated `toast` was skipped; use Sonner). Composed: `Banner`, `ConfirmDialog`, `DatePicker`/`DateRangePicker`, `FileUpload`, `NumberInput`, `DataList`, `Timeline`, `Stepper`, `ColorSwatches`, `CommandPalette`, `DataTable`, `PasswordInput`, `SearchInput`, `ModeToggle`, `Gauge`, `BarChannel`, `HeatCell`, `NumberTicker`. `Combobox` gained `wide` and per-option `detail`.

## Not covered by the Mecano list but in the shadcn set

`Slider`, `Resizable`, `Chart`, `Collapsible`, `ToggleGroup`, `Sheet`/`Drawer`, `Form`, `Calendar`: no forge counterpart was in Mecano's import list.
